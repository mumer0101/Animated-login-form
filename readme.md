# Animated Login Form

A beautifully **animated login form** built using HTML and CSS. This form features glowing borders, smooth animations, floating labels, and a sleek modern UI.

---

## Preview

> A glowing login box with animated borders and interactive form inputs.

![Preview](https://via.placeholder.com/600x350.png?text=Login+Box+Preview)

---

## Technologies Used

- **HTML5**
- **CSS3**
- [Google Fonts - Poppins](https://fonts.google.com/specimen/Poppins)

---

## Features

- Responsive, center-aligned layout
- Floating label inputs
- Glowing animated border with `@keyframes`
- Smooth transition effects
- Custom styled links and buttons

---
## How to Run

1. Download or clone this repository.
2. Ensure `index.html` and `style.css` are in the same folder.
3. Open `index.html` in your web browser.
